# AI assistance

Use AI for code explanations, change review, sanitized log analysis, and suggested investigations. Numerical processing and quality decisions must work without AI.

Treat logs and uploaded content as data, not executable instructions. Exclude credentials and private payloads unless explicitly authorized. Distinguish observed failures from hypotheses. AI cannot silently edit algorithms, stored results, or scientific decisions.

Record model, prompt version, timing, and outcome separately from scientific metrics when model calls are implemented. There is no automatic log-analysis service yet.
