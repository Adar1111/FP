# Open questions

- Instrument file format and channel labels?
- Main and auxiliary channels in one file or separate files?
- Available sample-rate, timing, units, delay, and calibration metadata?
- Sweep boundaries and directions?
- Supervisor-approved auxiliary model and resampling method?
- Reference measurements, quality metrics, and acceptance thresholds?
- File export only, or instrument acquisition adapters too?
- Typical file size, memory requirement, and processing duration?
- Data visibility and retention requirements?

Do not encode guessed answers as mandatory schemas or scientific defaults.
